# Marketing Website — version 1.0

Repository upload: 3 November 2026.

This snapshot is the Ask Fareej public-facing marketing website and interactive product showcase. It includes the official supplied logo, larger responsive typography, scroll-driven phone concepts, a fictional community map, curated assistant responses, a concept gallery, a management dashboard visual and a validated enquiry-draft download.

The UI previews are illustrative. This snapshot does not implement the resident app or management platform. No live AI, utility integration, real community data, pricing, partnership claims or enquiry delivery service is included.

Stack: React, TypeScript, Vite and Lucide React.

See QA.md for browser checks and their limits.
